# Experiment: planning for new categories instead of richness

Generated by `python -m abyss.evaluation.novelty_experiment report`.

## Question

ABYSS predicts richness, so it can return to rich habitat full of organisms it already knows.
Would it find more by aiming for new categories?

## Method

The appealing formula, the sum of P(category | habitat) over undiscovered categories, can't
be computed: undiscovered categories have no observations to learn from. Subtracting known
categories from richness doesn't help either, because every observed organism is already known.

So `abyss-novelty` trains the same Bayesian model on how many new categories each survey found,
and gradually forgets older surveys (forgetting 0.9, frozen on development seeds 0-19).
It ran on fresh seeds 2000-2049, not used to judge any planner before: 3600 missions, 3600 safe returns. Perception is ideal, and biology is simulated.

## Result

**It did not improve on ABYSS.** Of 18 world settings, it was clearly below ABYSS in 10,
clearly above in 1, and unclear in 7. "Clearly" means the 95% interval excludes zero, with no
correction for multiple comparisons. ABYSS keeps its richness target, and this planner stays experimental.

We only tested this one version, so it doesn't rule out other ways to target novelty, such as a
true per-category model of categories already seen.
